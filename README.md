# Data Hmamat

تطبيق أندرويد **أوفلاين** لتسجيل بيانات الحمام (الطيور) الخاصة بك، مع شجرة نسب، وسجل صور أسبوعية قابلة للتكبير.

## المميزات

- **بيانات الطير:** الاسم، النوع/السلالة، اللون، الجنس، رقم الحلقة، تاريخ الولادة، و«سيرة ذاتية» للطير (CV).
- **شجرة النسب:** ربط كل طير بأبيه وأمه، وعرض الأجداد شجرياً والأبناء المباشرون.
- **صور أسبوعية:** يظهر «شعار» في الواجهة عندما يستحق طير صورته. يمكنك التقاط صورة من الكاميرا أو المعرض، أو **تأجيل** الموعد، أو **تخطي** الأسبوع؛ ويُحفظ وقت الموعد الأصلي في السجل.
- **صور قابلة للتكبير:** كل صورة تدعم السحب والتقريب حتى ٦ أضعاف، والنقر المزدوج يعيدها للحجم الأصلي.
- **تخزين على جهازك:** تختار مجلد الحفظ من الإعدادات؛ تُحفظ `birds.json` والصور داخله. لا يوجد إنترنت ولا رفع لأي خادم.

## البناء والنشر

- `Build APK` يعمل عند كل دفع إلى `main`.
- عند دفع وسم مثل `v0.1.0` ينشئ `release.yml` إصداراً عاماً مرفقاً بملف `app-release.apk`.
- كل الإصدارات موقّعة بنفس مفتاح التوقيع المخزّن في أسرار GitHub، حتى تعمل التحديثات لاحقاً.

## الخصوصية

كل شيء محلي. حتى لو توقف التطبيق لن تفقد بياناتك؛ إن نقلت مجلد الحفظ إلى جهاز آخر استعدت سجلك كاملاً.
